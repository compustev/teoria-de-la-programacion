Algoritmo222
En una panaderia, construya un algoritmo que lea la edad (entero) de una persona. Use una constante simbolica MAYORIA_EDAD = 18. Evalúe la expresion relacional (edad >= MAYORIA_EDAD). Asigne el resultado booleano a es_mayor. Muestre por pantalla si la persona es mayor o menor de edad. Justifique el tipo de dato de cada variable. Ademas, calcule el triple del resultado si este es positivo. Asegurese de que las expresiones logicas esten bien parentizadas.
Inicio
//--------------------------------------------
//DESCRIPCION DE PASOS A SEGUIR:
//1. Declarar la constante simbolica MAYORIA_EDAD = 18.
//2. Justificar el tipo de dato de cada variable utilizada.
//3. Leer la edad de la persona (entero).
//4. Evaluar la expresion relacional parentizada (edad >= MAYORIA_EDAD) y asignarla a es_mayor (booleano).
//5. Mostrar por pantalla si la persona es mayor o menor de edad.
//6. Validar si la edad es positiva (edad > 0) y calcular su triple.
//--------------------------------------------

//JUSTIFICACION DE TIPOS DE DATOS:
//- MAYORIA_EDAD: constante entera (18), representa el umbral legal de edad.
//- edad: entero, la edad de una persona se mide en anos completos sin decimales.
//- es_mayor: booleano (logico), almacena el resultado de la expresion relacional (Verdadero o Falso).
//- triple_edad: entero, el producto de multiplicar un numero entero (edad) por 3 resulta en un entero.
 

//Constante simbolica 
MAYORIA_EDAD = 18 ;
//Lectura y declaracion
Leer edad ;

//Evaluacion 

es_mayor = (edad >= MAYORIA_EDAD) ;
Si es_mayor  entonces ;
Escribir "La persona es mayor de edad." ;
SiNo ;
Escribir "La persona es menor de edad." ;
FinSi ;
// Triple edad
Si (edad > 0) entonces
triple_edad = edad * 3 ;
Escribir "El triple de la edad ingresada es: ", triple_edad ;
SiNo ;
Escribir "La edad ingresada no es un valor positivo, no se calcula el triple." ;
triple_edad = 0 ;
FinSi ;

// Resumen de datos al final
Escribir "--------------------------------------------------" ;
Escribir "                RESUMEN DE DATOS                  " ;
Escribir "--------------------------------------------------" ;
Escribir "Edad ingresada: ", edad ;
Escribir "Constante MAYORIA_EDAD: ", MAYORIA_EDAD ;
Escribir "Resultado booleano (es_mayor): ", es_mayor ;
Escribir "Triple calculado: ", triple_edad ;
Escribir "--------------------------------------------------" ;

Fin
